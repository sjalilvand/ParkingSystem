 بستهٔ دوربین — حالت HTTP snapshot (بدون RTSP/H265) — ۲۰۲۶-۱۱-۰۵ (v2)
=====================================================================

■ کشف مهم این مرحله

تصاویر دوربین نشان داد: استریم‌های Main و Sub دوربین شما **H265** هستند و
فقط MJPEG/HTTP درست کار می‌کند. در کانتینر، استریم H265 ناپایدار است
(همین باعث «قطع» و تصویر سیاه می‌شد). پس حالت جدید اضافه شد:

   ★ حالت HTTP — دوربین با آدرس HTTP snapshot کار می‌کند؛ بدون RTSP،
     بدون codec، بدون سشن پایدار. همین آدرسی که خودتان تست کرده بودید.

■ مراحل نصب

   ۱) استخراج zip (PowerShell، overwrite مستقیم در ریشهٔ پروژه):

      Expand-Archive -Path "E:\ParkingSystem\parking-camera-http-fix.zip" -DestinationPath "E:\ParkingSystem" -Force

   ۲) rebuild:

      .\UPDATE-AND-RUN.ps1 -Prod

   ۳) در سامانه (پنل گیت → تنظیمات دوربین) برای هر دو دوربین این آدرس را
      بگذارید و ذخیره کنید (سطح دوربین خودتان را جایگزین کنید):

      IN : http://admin:admin@192.168.100.230/jpgimage/1/image.jpg
      OUT: http://admin:admin@192.168.100.231/jpgimage/1/image.jpg

      سپس «تست اتصال» — باید «اتصال موفق» ببینید و پیش‌نمایش زنده تصویر
      می‌دهد (هر ~۱ ثانیه فریم تازه). خواندن خودکار پلاک هم از همین
      فریم‌ها انجام می‌شود (سناریو B — بدون تغییر دیگر).

   ۴) دوربین‌ها را یک‌بار Power-cycle کنید (برق را بکشید و وصل کنید) —
      سرویس RTSP دوربین بعد از روزها probe احتمالاً گیر کرده؛ reboot
      برای برگرداندن RTSP (برای بعداً) خوب است ولی برای حالت HTTP لازم نیست.

■ اگر باز هم مشکل بود — تشخیص کامل داخل کانتینر:

      docker exec parkingsystem-prod-backend-1 python -m scripts.cam_probe

   این اسکریپت چاپ می‌کند: پیکربندی DB، باز بودن پورت‌ها، نتیجهٔ HTTP
   snapshot با رزولوشن، نتیجهٔ RTSP main/sub با تعداد فریم decode شده.
   خروجی کامل را بفرستید.

■ لاگ — حالا دلیل قطعی‌ها در log می‌آید:

      docker logs parkingsystem-prod-backend-1 --tail 100 2>&1 | Select-String "\[camera"

   خطوط مورد انتظار:
      [camera:IN] HTTP snapshot فعال — فریم 1920x1080   ← رزولوشن واقعی
      [camera:IN] heartbeat connected=True …            ← هر ۵ دقیقه
      [camera:IN] HTTP snapshot ناموفق (تلاش N)         ← فقط اگر مشکل باشد

■ نکتهٔ OCR

رزولوشنِ snapshot را لاگ می‌بینید. اگر ۱۹۲۰x۱۰۸۰ بود عالی است؛ اگر ۶۴۰x۴۸۰
بود، پلاکِ دور باید بزرگ‌تر در کادر بیفتد (زاویه/فاصلهٔ دوربین) یا در تنظیمات
Video دوربین، اندازهٔ عکس snapshot را بزرگ‌تر کنید.
