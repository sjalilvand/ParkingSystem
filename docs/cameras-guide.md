# راهنمای دوربین‌های گیت — سناریو A و B (نسخهٔ فعال‌شده)

این سند نحوهٔ اتصال دوربین‌های ورود/خروج به سامانه را شرح می‌دهد. هر دو سناریو
با استقرار production فعلی (docker + nginx روی پورت سامانه) کار می‌کنند و
**هیچ نرم‌افزار جانبی روی ویندوز لازم نیست** — همه‌چیز داخل سرور اجرا می‌شود.

---

## سناریو A — دوربین پلاک‌خوان ANPR (پیشنهادی برای راهبند)

برای دوربین‌هایی که خودشان پلاک را می‌خوانند (Hikvision ANPR، Dahua ITC، ...).

### تنظیم در سامانه
1. وارد پنل شوید → **پنل گیت** → روی کارت گیت، دکمهٔ **«تنظیمات دوربین»** را بزنید.
2. در کادر «سناریو A» روی دکمهٔ **کپی** بزنید — نشانی زیر را به شما می‌دهد:
   ```
   http://<آدرس-سرور>:<پورت>/api/v1/gate/events/anpr/GATE-IN-01/IN?api_key=<کلید گیت>
   ```
   برای گیت خروج همان کارت OUT نشانی `.../anpr/GATE-OUT-01/OUT?api_key=...` می‌دهد.

### تنظیم در دوربین (Hikvision)
- مسیر: `Configuration → Network → Advanced Settings → HTTP Listening` یا
  `Configuration → Event → Normal Event → Line Crossing / Motion → Linkage Method → Notify Surveillance Center`
- آدرس HTTP Event را همان نشانی بالا بگذارید (پروتکل HTTP، متد POST).
- در Dahua: `Event Management → Video Detection → Report Center` — آدرس بالا + افزونهٔ `&plate=` در قالب Body.

### قالب‌های پذیرفته‌شده توسط سرور
سرور پلاک را از هرکدام می‌کشد:
- **Query string**: `?plate=12ب345ایران67` یا `?plateNumber=12B345IR67`
- **JSON** تودرتو با هر کلیدی از: `plate / plateNumber / plate_number / plateNo / licensePlate / LPNumber / carNumber`
- **XML**: `<plateNumber>12B345IR67</plateNumber>` یا `<plate>...</plate>`
- **متن خام**: هر الگوی پلاک ایرانی در متن (مثل `12ب345ایران67` یا `12B345IR67`)
- **multipart (ISAPI Hikvision)**: بخش XML + عکس
- ارقام فارسی/عربی خودکار لاتین می‌شوند و پلاک نرمال می‌شود (12ب345ایران67 → 12B345IR67).

پاسخ سرور:
```json
{"ok": true, "decision": "ALLOW", "decision_reason": "VALID_PERMIT",
 "barrier_action": "OPEN", "duplicate": false, "plate": "12B345IR67"}
```

## سناریو B — دوربین معمولی IP (RTSP) + خواندن پلاک توسط سرور

برای دوربین‌های معمولی که خودشان پلاک نمی‌خوانند. سرور خودش هر چند ثانیه
عکس می‌گیرد و با موتور OCR داخلی (همان موتور صفحهٔ «آزمایش پلاک‌خوان») پلاک را می‌خواند.

### تنظیم در سامانه
1. پنل گیت → **«تنظیمات دوربین»** (روی کارت IN یا OUT).
2. آدرس RTSP دوربین را وارد کنید:
   - Hikvision: `rtsp://user:pass@IP-دوربین:554/Streaming/Channels/101`
   - Dahua: `rtsp://user:pass@IP-دوربین:554/cam/realmonitor?channel=1&subtype=0`
3. «دوربین فعال باشد» را روشن کنید → **ذخیره** → **تست اتصال** (فریم زنده نمایش داده می‌شود).
4. تمام — چراغ «زنده» روشن می‌شود و **خواندن خودکار پلاک** شروع می‌شود.
   هر پلاک خوانده‌شده همان مسیر عادی گیت می‌رود: تصمیم + اعلان + (در صورت مجاز) فرمان راهبند.

### تنظیمات تکمیلی
| مورد | مقدار پیش‌فرض | توضیح |
|------|---------------|-------|
| فاصلهٔ خواندن خودکار | ۱۰ ثانیه | در همان پنجرهٔ تنظیمات قابل تغییر (۳ تا ۱۲۰ ثانیه) |
| حداقل اطمینان | ۰٫۳۰ | متغیر محیطی `CAMERA_MIN_CONF` |
| جلوگیری از تکرار | ۲۰ ثانیه | پلاک تکراری در این بازه رویداد دوباره نمی‌سازد (`CAMERA_DEDUPE_TTL`) |
| خاموش/روشن کل حلقه | روشن | `CAMERA_POLL_ENABLED=true/false` در .env.prod |
| رلهٔ راهبند واقعی | خاموش | اگر راهبند سخت‌افزاری دارید `BARRIER_RELAY_URL` را در .env.prod بگذارید — فرمان OPEN به آن POST می‌شود |

### نکته‌های عملی
- عکس‌های گرفته‌شده در `docker volume` (مسیر `/data/cameras` کانتینر بک‌اند) نگه داشته می‌شوند
  و پنل گیت تصویر زندهٔ همان را هر ۳ ثانیه تازه می‌کند.
- اگر دوربین در شبکهٔ همان سرور است ولی از داخل کانتینر باز نمی‌شود، فایروال ویندوز را برای
  پورت 554 ورودی از Docker باز کنید.
- کیفیت خوانش با «عکس مستقیم دوربین» به‌مراتب بهتر از اسکرین‌شات موبایل است؛ در شب
  WDR/شب‌بین دوربین را روشن کنید.
- فقط **یک worker** دوربین‌ها را می‌خواند (قفل Redis) — با دو worker هم رویداد تکراری ساخته نمی‌شود.

## اجرای دستی «عکس + خواندن پلاک»
روی هر کارت گیت دکمهٔ **«عکس + خواندن پلاک»** هست: همان لحظه فریم می‌گیرد، پلاک را
می‌خواند، و با `auto_emit=true` رویداد را ثبت می‌کند. برای تست سریع دوربین بدون انتظار
برای چرخهٔ خودکار مناسب است.

## عیب‌یابی
| نشانه | علت احتمالی | راه‌حل |
|-------|-------------|--------|
| چراغ «قطع» روی تصویر | RTSP اشتباه / فایروال / دوربین خاموش | «تست اتصال» را بزنید؛ پیام دقیق فارسی می‌دهد |
| «موتور پلاک‌خوان فعال نیست» | INSTALL_OCR=true نیست | در .env.prod → `.\UPDATE-AND-RUN.ps1 -Prod -Ocr` |
| پلاک خوانده می‌شود ولی UNKNOWN_PLATE | خودرو ثبت نشده | از «خودروها» پلاک را ثبت/مجوز بدهید |
| رویداد از دوربین ANPR نمی‌رسد | آدرس/کلید اشتباه در دوربین | نشانی کپی‌شده از پنل را دوباره بگذارید؛ لاگ: `docker compose -f docker-compose.prod.yml logs -f backend` |
