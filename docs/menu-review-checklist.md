# چک‌لیست بازبینی منوی جدید (الحاقیه §۱) — سرور E:

پس از اجرای `UPDATE-AND-RUN.ps1` روی سرور E: و باز کردن `http://192.168.100.2` (یا
`http://localhost:5173` در حالت dev)، این چک‌لیست را با دو کاربر اجرا کنید.

## ورود

| کاربر | نقش (موجود) | انتظار |
|---|---|---|
| `admin` | ADMIN | همهٔ بخش‌ها |
| `op1` | نگهبان/اپراتور گیت (GUARD_IN) | فقط عملیاتی — بخش شبیه‌ساز مخفی |

## ۱) با admin — بخش «سامانه عملیاتی» (۱۱ گروه)

| # | کنترل | نتیجهٔ مورد انتظار |
|---|---|---|
| ۱ | دکمهٔ بزرگ «پنل گیت» بالای منو | درشت و پین‌شده؛ کلیک → صفحهٔ گیت؛ فعال بودن با رنگ |
| ۲ | بخش «سامانه عملیاتی» باز، «شبیه‌ساز و آزمون سناریوها» بسته | حالت پیش‌فرض |
| ۳ | کلیک روی هر گروهِ چندآیتمی | باز/بسته شدن زیرمجموعه |
| ۴ | گروه تک‌آیتمی (مثلاً «مجوزهای تردد») | یک کلیک مستقیم به مقصد (بدون لایه) |
| ۵ | گروه «همگام‌سازی و انطباق» → «همگام‌سازی خودروها (Sheets)» | صفحهٔ sync: کارت پوشش، تست اتصال، Dry-run، صف تعارض، تاریخچه |
| ۶ | گروه «گیت و تردد» → «بازبینی پلاک» | صفحهٔ صف تأیید انسانی + متریک p95 |
| ۷ | آیتم فعال | رنگ اصلی + بولد |

## ۲) با admin — بخش «شبیه‌ساز و آزمون سناریوها» (۹ گروه)

| # | کنترل | نتیجهٔ مورد انتظار |
|---|---|---|
| ۱ | چیپ نارنجی «آزمایشی» کنار عنوان بخش | نمایش داده شود |
| ۲ | هر ۵ صفحهٔ شبیه‌ساز (شبیه‌ساز/سناریوهای الزامی/سناریوساز/قوانین/پلاک‌خوان) | نوار هشدار «آزمایشی ـ فاقد اعتبار مالی و عملیاتی» بالای صفحه |
| ۳ | «کاتالوگ SIM-01..20» | ۲۰ کارت با پیش‌شرط/مراحل/نتیجهٔ مورد انتظار |
| ۴ | اجرای SIM-01 و SIM-02 (دکمهٔ اجرای خودکار) | نتیجهٔ PASS + JSON ردیاب + مدت اجرا |
| ۵ | کارت «جداسازی محیط» پایین صفحه | آدرس DB شبیه‌ساز (بدون پسورد) ≠ DB عملیاتی |
| ۶ | شمارش خودروها پس از SIM-01 در پنل عملیاتی (خودروها) | **بدون تغییر** — دادهٔ شبیه‌ساز به عملیاتی نمی‌ریزد |

## ۳) با op1 — فیلتر مجوز

| کنترل | نتیجهٔ مورد انتظار |
|---|---|
| ورود op1 | دکمهٔ پنل گیت + گروه‌های مجاز (داشبورد/گیت و تردد/خودرو/بدهی) |
| بخش شبیه‌ساز | **نمایش داده نشود** (نداشتن simulator.view) |
| نیاز به آموزش op1؟ | در «کاربران و نقش‌ها» مجوز `simulator.view` را از ماتریس به نقش/کاربر بدهید و دوباره وارد شوید |

## ۴) تست سریع پلاک‌خوان با همین عکس موبایل (کالیبراسیون اولیه)

1. منو → شبیه‌ساز → «پلاک‌خوان OCR» → آپلود `20261015_090357.jpg`
2. انتظار: کاندیدای معتبر قالب (مثل «93 ه 340») با اطمینان ~۰٫۶ در ۴-۵ ثانیه (CPU)
3. منو → عملیاتی → «بازبینی پلاک» → رکورد NEEDS_REVIEW همین خوانش → «اصلاح» →
   تایپ «72 ق 343 ایران 40» → ذخیره
4. کنترل: مقدار اصلی حفظ شده + اصلاح با نام کاربر ثبت شده است (ستون‌های جدا)

> اگر خوانش بالای ۰٫۷۰ بود، عبور خودکار؛ زیر آن حتماً صف بازبینی — همین
> رفتار مورد انتظار الحاقیه است. آستانه‌ها در «طراح تنظیمات → plate_envelope».
