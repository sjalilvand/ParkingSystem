# پلاک‌خوان ایرانی (Plate OCR) — راهنمای نصب و استفاده

> نسخه ۱.۰ — ماژول `backend/app/modules/plate_ocr`
> برگرفته از اسکریپت `plate_all.py` (پلاک‌خوان ایرانی v3) و تطبیق‌یافته به‌صورت سرویس وب

## ۱. معماری

```
تصویر آپلودی (POST /api/v1/plate-ocr/read)
        │
        ▼
┌───────────────────────────────────────────────────┐
│  تشخیص پلاک (Detector)                             │
│  1) YOLO  → اگر models/plate_det_best.pt موجود    │
│  2) کلاسیک CV → ماسک رنگ + کانتور + نسبت ابعاد     │
│  3) OCR روی کل تصویر → عکس‌های نزدیک از پلاک        │
└───────────────────────────────────────────────────┘
        │  برش + راست‌کردن (warp) + بهبود (CLAHE)
        ▼
┌───────────────────────────────────────────────────┐
│  خواندن نویسه‌ها (OCR)                              │
│  1) CRNN آموزش‌دیده → اگر models/crnn_best.pt       │
│  2) EasyOCR (fa+en) → پیش‌فرض، بدون نیاز به آموزش   │
└───────────────────────────────────────────────────┘
        │  کاندیداهای متنی (RTL + LTR)
        ▼
┌───────────────────────────────────────────────────┐
│  اعتبارسنجی: قالب پلاک ایران ۲رقم + حرف + ۳رقم      │
│  (+ کد استان) — ۱۴ حرف رسمی: بجدسصطعقلمنوهی        │
│  امتیازدهی: معتبر بودن × ۲ + اطمینان                │
└───────────────────────────────────────────────────┘
        │
        ▼
  خروجی JSON: بهترین پلاک + همه کاندیداها + رنگ پلاک
  + فرمت سیستم (12B345IR67) + تصویر حاشیه‌نویسی‌شده
```

**کاهش تدریجی قابلیت (graceful degradation):** هیچ‌یک از وابستگی‌های سنگین اجباری نیستند.
بدون `easyocr` سرویس بالا می‌آید و `/status` وضعیت را نشان می‌دهد؛ نصب بعدی بدون تغییر کد فعال می‌شود.

## ۲. نصب روی ویندوز (محیط توسعه محلی)

```powershell
cd D:\Projects\ParkingSystem\backend
# محیط مجازی پروژه را فعال کنید (در صورت وجود)

pip install -r requirements-ocr.txt
```

> ⚠️ بار اول که عکس می‌فرستید، EasyOCR مدل‌های خودش (~۱۰۰MB) را دانلود می‌کند — اینترنت لازم است و ممکن است ۲-۵ دقیقه طول بکشد. بعد از آن هر تحلیل روی CPU حدود ۱ تا ۳ ثانیه است.

### اختیاری — دقت بالاتر با مدل آموزش‌دیده

| فایل مدل | محل قرارگیری | اثر |
|---|---|---|
| `plate_det_best.pt` (YOLO تشخیص) | `backend\models\` | تشخیص دقیق پلاک در عکس‌های راهبند/دور، جایگزین تشخیص کلاسیک |
| `crnn_best.pt` (CRNN) | `backend\models\` | OCR سریع‌تر و دقیق‌تر روی پلاک‌های راست‌شده |

این فایل‌ها با اسکریپت `plate_all.py` (آموزش: `synth` → `train-ocr` → `train-det`) تولید می‌شوند
یا از مدل‌های آماده "iranian license plate" در Roboflow Universe قابل دریافت‌اند.
فقط فایل را در `backend\models\` بگذارید — موتور خودکار تشخیص می‌دهد (بدون تغییر کد).

## ۳. استفاده

### ۳-۱) محیط تست گرافیکی (توصیه‌شده)

بک‌اند را اجرا کنید و در مرورگر باز کنید:

```
http://localhost:8000/plate-test/
```

قابلیت‌ها: آپلود با کلیک/کشیدن-ورهاکردن/**چسباندن اسکرین‌شات (Ctrl+V)**،
نمایش بهترین پلاک با قالب استاندارد، درصد اطمینان، رنگ پلاک، برش پلاک،
تصویر تحلیل‌شده با جعبه‌ها، جدول همه کاندیداها، و جستجوی پلاک در خودروهای ثبت‌شده سیستم.

احراز هویت صفحه: کلید API گیت (`gate-dev-key` در توسعه) یا نام کاربری/رمز عبور.

### ۳-۲) API

**وضعیت موتور:**
```
GET /api/v1/plate-ocr/status
→ { "ready": true, "capabilities": { "opencv": true, "easyocr": true, ... } }
```

**خواندن پلاک:**
```
POST /api/v1/plate-ocr/read
Headers:  X-API-Key: gate-dev-key        (یا Authorization: Bearer <jwt>)
Body:     multipart/form-data — file=<image.jpg>
Query:    lookup=true   → جستجوی پلاک در vehicles (نیازمند مجوز vehicles.view یا کلید گیت)
          min_conf=0.25 → حداقل اطمینان OCR
```

نمونه خروجی:

```json
{
  "success": true,
  "best": {
    "raw": "12ب34567",
    "persian": "12 ب 345 | 67",
    "system": "12B345IR67",
    "valid": true,
    "confidence": 0.91,
    "method": "classical+easyocr",
    "color": "سفید (شخصی)",
    "box": [152, 194, 648, 288],
    "crop_b64": "…"
  },
  "plates": [ … همه کاندیداها … ],
  "vehicles": [ … در حالت lookup … ],
  "engine": { "detector": "classical", "ocr": "easyocr" },
  "elapsed_ms": 1420,
  "annotated_b64": "…"

```

فرمت `system` با `vehicles.plate_normalized` سیستم یکسان است
(`app/shared/plate.py` → نگاشت D8) و مستقیماً برای جستجوی خودرو/مجوز قابل استفاده است.

## ۴. تنظیمات (متغیرهای محیطی / .env)

| کلید | پیش‌فرض | توضیح |
|---|---|---|
| `PLATE_OCR_MODELS_DIR` | `models` | محل وزن‌های YOLO/CRNN نسبت به پوشه backend |
| `PLATE_OCR_MAX_IMAGE_MB` | `12` | حداکثر حجم آپلود |
| `PLATE_OCR_MAX_IMAGE_PX` | `2600` | بزرگ‌ترین ضلع تصویر ورودی (بزرگ‌ترها کوچک می‌شوند) |
| `PLATE_OCR_MIN_CONF` | `0.25` | حداقل اطمینان پیش‌فرض |

## ۵. نکات فنی

- **قالب معتبر پلاک:** `۲ رقم + حرف + ۳ رقم` و اختیاری `+ ۲ رقم کد استان` — حرف از مجموعه
  ۱۴ حرف رسمی (ب ج د س ص ط ع ق ل م ن و ه ی). خروجی نامعتبر هم برگردانده می‌شود ولی با `valid=false`.
- **کلمه «ایران»** قبل از پاکسازی حذف می‌شود تا با حروف پلاک اشتباه نشود.
- **RTL/LTR:** چون ترتیب بصری بخش‌های پلاک از راست به چپ است، هر دو چینش قطعات OCR
  امتحان و معتبرترین انتخاب می‌شود (الگوی `plate_all.py`).
- **enforce_format:** وقتی متن نامعتبر با قالب ۶/۸ نویسه‌ای است، حرفِ موقعیت سوم از روی
  شباهت بصری رقم‌ها اصلاح می‌شود — کاندیدای حاصل با اطمینان کمتر (×۰.۹۵) رتبه می‌گیرد.
- **رنگ پلاک:** از روی هیستوگرام HSV ناحیه مرکزی → سفید=شخصی، زرد=عمومی،
  قرمز=موقت، آبی=دیپلمات، سبز=مخصوص.
- **thread-safety:** مدل‌ها با قفل lazy-load می‌شوند و فراخوانی OCR در threadpool انجام
  می‌شود تا event-loop بلاک نشود.
- **تشخیص کلاسیک:** برای عکس‌های نزدیک و واضح خوب است؛ برای عکس‌های راهبندِ دور/مورب
  مدل YOLO آموزش‌دیده به‌طور محسوس بهتر عمل می‌کند.
