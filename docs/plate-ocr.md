# پلاک‌خوان ایرانی (Plate OCR) — راهنمای نصب و استفاده

> نسخه ۱.۰ — ماژول `backend/app/modules/plate_ocr`
> برگرفته از اسکریپت `plate_all.py` (پلاک‌خوان ایرانی v3) و تطبیق‌یافته به‌صورت سرویس وب

## ۱. معماری

```
تصویر آپلودی (POST /api/v1/plate-ocr/read)
        │
        ▼
┌───────────────────────────────────────────────────┐
│  تشخیص پلاک (Detector)                             │
│  1) YOLO  → اگر models/plate_det_best.pt موجود    │
│  2) کلاسیک CV → ماسک رنگ + کانتور + نسبت ابعاد     │
│  3) OCR روی کل تصویر → عکس‌های نزدیک از پلاک        │
└───────────────────────────────────────────────────┘
        │  برش + راست‌کردن (warp) + بهبود (CLAHE)
        ▼
┌───────────────────────────────────────────────────┐
│  خواندن نویسه‌ها (OCR)                              │
│  1) CRNN آموزش‌دیده → اگر models/crnn_best.pt       │
│  2) Hezar CRNN → مدل آموزش‌دیده برای پلاک ایران     │
│  3) EasyOCR (fa+en) → مسیر پشتیبان                  │
└───────────────────────────────────────────────────┘
        │  کاندیداهای متنی (RTL + LTR)
        ▼
┌───────────────────────────────────────────────────┐
│  اعتبارسنجی: قالب پلاک ایران ۲رقم + حرف + ۳رقم      │
│  (+ کد استان) — ۱۴ حرف رسمی: بجدسصطعقلمنوهی        │
│  امتیازدهی: معتبر بودن × ۲ + اطمینان                │
└───────────────────────────────────────────────────┘
        │
        ▼
  خروجی JSON: بهترین پلاک + همه کاندیداها + رنگ پلاک
  + فرمت سیستم (12B345IR67) + تصویر حاشیه‌نویسی‌شده
```

**کاهش تدریجی قابلیت (graceful degradation):** هیچ‌یک از وابستگی‌های سنگین اجباری نیستند.
سرویس بدون بسته‌های OCR هم بالا می‌آید. `/status` نشان می‌دهد کدام بسته‌ها نصب شده‌اند.

## ۲. نصب روی ویندوز (محیط توسعه محلی)

```powershell
cd D:\Projects\ParkingSystem\backend
# محیط مجازی پروژه را فعال کنید (در صورت وجود)
.\.venv\Scripts\Activate.ps1

pip install -r requirements-ocr.txt
```

در اولین راه‌اندازی پس از نصب، بک‌اند مدل Hezar (حدود ۳۶ مگابایت) و مدل‌های EasyOCR را در پس‌زمینه دانلود می‌کند. برای این مرحله دسترسی به Hugging Face و GitHub لازم است. مدل Hezar در پوشهٔ کش EasyOCR ذخیره می‌شود. نصب Docker این پوشه را در حجم دادهٔ `easyocr` نگه می‌دارد.

Hezar برش پلاک را یکجا می‌خواند تا کد استان همراه با بدنهٔ پلاک خوانده شود. پذیرش مستقیم به قالب کامل، کد استان شناخته‌شده و حداقل اطمینان ۰٫۷۰ برای ضعیف‌ترین نویسه وابسته است. خوانش ناقص یا کم‌اطمینان به مسیر پشتیبان واگذار می‌شود. در صورت شکست دانلود، پس از بازیابی دسترسی اینترنت بک‌اند را دوباره راه‌اندازی کنید. [مدل Hezar](https://huggingface.co/hezarai/crnn-fa-license-plate-recognition-v2)

برای نصب Production، از ریشهٔ مخزن در PowerShell اجرا کنید تا بک‌اند با بسته‌های OCR دوباره ساخته شود.

```powershell
.\UPDATE-AND-RUN.ps1 -Prod -Ocr
```

### اختیاری — دقت بالاتر با مدل آموزش‌دیده

| فایل مدل | محل قرارگیری | اثر |
|---|---|---|
| `plate_det_best.pt` (YOLO تشخیص) | `backend\models\` | تشخیص دقیق پلاک در عکس‌های راهبند/دور، جایگزین تشخیص کلاسیک |
| `crnn_best.pt` (CRNN) | `backend\models\` | OCR سریع‌تر و دقیق‌تر روی پلاک‌های راست‌شده |

این فایل‌ها با اسکریپت `plate_all.py` (آموزش: `synth` → `train-ocr` → `train-det`) تولید می‌شوند
یا از مدل‌های آماده "iranian license plate" در Roboflow Universe قابل دریافت‌اند.
فقط فایل را در `backend\models\` بگذارید — موتور خودکار تشخیص می‌دهد (بدون تغییر کد).

### ۳-۲) API

**وضعیت موتور:**
```
GET /api/v1/plate-ocr/status
→ { "ready": true, "capabilities": { "opencv": true, "easyocr": true, ... } }
```

**خواندن پلاک:**
```
POST /api/v1/plate-ocr/read
Headers:  X-API-Key: gate-dev-key        (یا Authorization: Bearer <jwt>)
Body:     multipart/form-data — file=<image.jpg>
Query:    lookup=true   → جستجوی پلاک در vehicles (نیازمند مجوز vehicles.view یا کلید گیت)
          min_conf=0.25 → حداقل اطمینان OCR
```

نمونه خروجی:

    "color": "سفید (شخصی)",
    "box": [152, 194, 648, 288],

## ۴. تنظیمات (متغیرهای محیطی / .env)

| کلید | پیش‌فرض | توضیح |
|---|---|---|
| `PLATE_OCR_MODELS_DIR` | `models` | محل وزن‌های YOLO/CRNN نسبت به پوشه backend |
| `PLATE_OCR_MAX_IMAGE_MB` | `12` | حداکثر حجم آپلود |
| `PLATE_OCR_MAX_IMAGE_PX` | `2600` | بزرگ‌ترین ضلع تصویر ورودی (بزرگ‌ترها کوچک می‌شوند) |
| `PLATE_OCR_MIN_CONF` | `0.25` | حداقل اطمینان پیش‌فرض |

## ۵. نکات فنی

- **قالب معتبر پلاک:** `۲ رقم + حرف + ۳ رقم` و اختیاری `+ ۲ رقم کد استان` — حرف از مجموعه
  ۱۴ حرف رسمی (ب ج د س ص ط ع ق ل م ن و ه ی). خروجی نامعتبر هم برگردانده می‌شود ولی با `valid=false`.
- **کلمه «ایران»** قبل از پاکسازی حذف می‌شود تا با حروف پلاک اشتباه نشود.
- **RTL/LTR:** چون ترتیب بصری بخش‌های پلاک از راست به چپ است، هر دو چینش قطعات OCR
  امتحان و معتبرترین انتخاب می‌شود (الگوی `plate_all.py`).
- **enforce_format:** وقتی متن نامعتبر با قالب ۶/۸ نویسه‌ای است، حرفِ موقعیت سوم از روی
  شباهت بصری رقم‌ها اصلاح می‌شود — کاندیدای حاصل با اطمینان کمتر (×۰.۹۵) رتبه می‌گیرد.
- **رنگ پلاک:** از روی هیستوگرام HSV ناحیه مرکزی → سفید=شخصی، زرد=عمومی،
  قرمز=موقت، آبی=دیپلمات، سبز=مخصوص.
- **thread-safety:** مدل‌ها با قفل lazy-load می‌شوند و فراخوانی OCR در threadpool انجام
  می‌شود تا event-loop بلاک نشود.
- **تشخیص کلاسیک:** برای عکس‌های نزدیک و واضح خوب است؛ برای عکس‌های راهبندِ دور/مورب
  مدل YOLO آموزش‌دیده به‌طور محسوس بهتر عمل می‌کند.

## ۶. فعال‌سازی روی سرور (Docker / prod)

```powershell
# ۱) فعال‌سازی — سوییچ آماده (INSTALL_OCR=true را در .env.prod ثبت و build می‌کند):
.\UPDATE-AND-RUN.ps1 -Prod -Ocr

#   یا دستی:
#      خط INSTALL_OCR=true به .env.prod اضافه کنید، سپس:
#      docker compose --env-file .env.prod -f docker-compose.prod.yml build backend
#      docker compose --env-file .env.prod -f docker-compose.prod.yml up -d

# ۲) بررسی وضعیت موتور:
#      http://<سرور>/api/v1/plate-ocr/status
# ۳) تست:
#      • منوی سامانه: «آزمایش پلاک‌خوان ← پلاک‌خوان OCR»  (مسیر /plate-ocr)
#      • صفحهٔ مستقل:  http://<سرور>/plate-test/
```

- بیلد بار اول سنگین‌تر است (torch CPU حدود ۲۲۰MB + opencv/easyocr)؛ لایه‌های بعدی کش می‌شوند.
- بار اول اجرای OCR، مدل‌های EasyOCR (حدود ۱۰۰MB) دانلود و روی volume «easyocr» ماندگار
  می‌شوند — rebuildهای بعدی آن را حفظ می‌کنند (به اینترنت نیاز دارد، فقط یک‌بار).
- وزن‌های اختیاری YOLO/CRNN را اگر داشتید در `backend/models/` بگذارید
  (`plate_det_best.pt` / `crnn_best.pt`) تا به‌جای تشخیص کلاسیک استفاده شوند.


## آزمون خوانش نسخهٔ ۲٫۷٫۵

برای مقایسه، ۱۰۰ تصویر واقعی و برش‌خورده از بخش Faster R-CNN مجموعهٔ ALPR_Dataset انتخاب شد. شناسهٔ تصاویر به‌ترتیب واژه‌نامه‌ای مرتب و با بذر `39174` در Python به‌هم زده شد. ۱۰۰ پلاک یکتای اول با هشت نویسه، یک حرف رسمی در جایگاه سوم و برچسب رقمی در بقیهٔ جایگاه‌ها وارد آزمون شدند. برچسب مرجع با مرتب‌کردن کادر نویسه‌ها بر اساس مختصات افقی ساخته شد. متن کامل هیچ پلاک و هش هیچ تصویر در سه بخش مجموعهٔ منتشرشدهٔ آموزش Hezar تطابق نداشت. [مجموعهٔ آزمون](https://github.com/roozbehrajabi/ALPR_Dataset/tree/51da29fd58e8f772f5daf224f7f52967277fcf29/Faster_R-CNN_dataset) · [مجموعهٔ منتشرشدهٔ Hezar](https://huggingface.co/datasets/hezarai/persian-license-plate-v1)

هر دو نسخه از مسیر `PlateReader.read_image` با تشخیص کلاسیک، تنظیمات پیش‌فرض، و مدل‌های بارگذاری‌شده روی CPU اجرا شدند. «خوانش کامل» یعنی انتخاب اول موتور با هر هشت نویسهٔ مرجع، شامل کد استان، یکسان باشد. سه عکس مخزن که پلاک از قبل در آن‌ها برش نخورده بود جداگانه آزمایش شدند. اعداد این آزمون به تصاویر بررسی‌شده مربوط‌اند. عملکرد دوربین نصب‌شده در محل هنوز اندازه‌گیری نشده است.

| معیار | نسخهٔ ۲٫۷٫۴ | نسخهٔ ۲٫۷٫۵ |
|---|---:|---:|
| خوانش کامل با کد استان | ۰ از ۱۰۰ | ۷۹ از ۱۰۰ |
| خوانش بخش اصلی پلاک بدون احتساب کد استان | ۷ از ۱۰۰ | ۸۱ از ۱۰۰ |
| بدون هیچ کاندیدا | ۵ از ۱۰۰ | ۲ از ۱۰۰ |
| خوانش کامل در عکس‌های برش‌نخوردهٔ مخزن | ۰ از ۳ | ۳ از ۳ |

در نسخهٔ جدید، انتخاب اول برای ۱۹ برش با مرجع تفاوت داشت و برای دو برش هیچ کاندیدایی به دست نیامد. ۵۸ آزمون مرتبط بک‌اند، بارگذاری مدل از کش خالی، درخواست آپلود از API و ساخت فرانت‌اند موفق بودند.

## بهبود تشخیص در نسخهٔ ۲٫۷٫۶

اگر تشخیص کلاسیک و Hezar به خوانش کامل و قابل‌قبول نرسند، مدل YOLOv9 با ONNX Runtime روی CPU جای پلاک را دوباره پیدا می‌کند. برای جعبه‌های این مدل، موتور خوانش برش خام و اصلاح پرسپکتیو را امتحان می‌کند. درخواست‌هایی که از برش اولیه نتیجه می‌گیرند این مرحله را طی نمی‌کنند. برای عکس‌هایی که قبلاً تا لبهٔ پلاک برش خورده‌اند، چند حاشیهٔ باریک آزمایش می‌شود تا نویسه‌های کناری در ورودی مدل بهتر حفظ شوند.

وزن مدل تشخیص حدود ۸ مگابایت است و در کنار مدل‌های OCR ذخیره می‌شود. اگر مدل در دسترس نباشد، مسیر پشتیبان EasyOCR فعال می‌ماند. [مدل تشخیص پلاک](https://github.com/ankandrew/open-image-models#plate-detection)

| خوانش کامل با کد استان | نسخهٔ ۲٫۷٫۵ | نسخهٔ ۲٫۷٫۶ |
|---|---:|---:|
| ۱۴ عکس کامل آرشیو کاربر | ۹ از ۱۴ | ۱۳ از ۱۴ |
| ۱۰۰ برش واقعی مجموعهٔ آزمون بالا | ۷۹ از ۱۰۰ | ۸۸ از ۱۰۰ |

در مجموعهٔ ۱۰۰تایی، هر ۷۹ نتیجهٔ صحیح قبلی حفظ شد. عکس‌های آرشیو در تشخیص خطا و توسعهٔ اصلاحات استفاده شدند. این نتایج آزمون مستقل دوربین نصب‌شده را پوشش نمی‌دهند.
