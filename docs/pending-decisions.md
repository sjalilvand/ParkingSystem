# تصمیمات معلق — نیازمند تصویب کارفرما (v0.1)

طبق سند §۲۳، موارد زیر قبل از فعال‌سازی قطعی باید تصویب شوند. سیستم فعلاً با گزینهٔ محافظه‌کارانه/وضعیت فعلی کار می‌کند.

| ID | موضوع | گزینه‌ها | وضعیت فعلی | محل اعمال |
|----|-------|---------|------------|-----------|
| D1 | سیاست خروج خودرو با بدهی پرداخت‌نشده (§۱۳/§۲۳) | ALLOW / WARN / DENY | WARN (خروج آزاد + هشدار) | env: EXIT_UNPAID_POLICY |
| D2 | قاعده گردکردن تعرفه | ساعتی رو به بالا / دقیقه‌ای | ساعتی رو به بالا | calculate_amounts |
| D3 | فرمول سقف روزانه در توقف چندروزه | daily_max × روزها | daily_max × ceil(روز) | calculate_amounts |
| D4 | تعرفه شب (night_amount) | فعال / غیرفعال | مدل موجود، بلااستفاده (F11) | کد + تست |
| D5 | نمونه‌های §۲۳ (مثل ۸۰۰ دقیقه = صفر) | تأیید / اصلاح | اعمال نشده | ماتریس نهایی |
| D6 | نقش‌های دارای gate.manual_access و gate.barrier_open | تعیین نقش‌ها | فقط ADMIN | seed RBAC |
| D7 | حداقل مبلغ محاسبه و مهلت خروج پس از پرداخت | تعیین | اعمال نشده | کد |
