## کشف‌های مهم آزمون‌ها (باگ واقعی که تست‌ها گرفتند)
1. F24: flush پرداخت بیرون از try → 500 در تداخل همزمان (تست همزمانی یافت و اصلاح شد)
2. عدم هم‌ترازی ایندکس جزئی مدل↔migration (تست هم‌زمانی ورود)
3. backup 0805 صفر بایتی (Docker خاموش) — فرایند پشتیبان باید زمان‌بندی شود (REQ-17-01)

## محدودیت‌ها (صادقانه)
- هم‌زمانی در یک پروسه/loop است؛ تست چندپروسه‌ای واقعی انجام نشده
- UI (باکس‌ها، ماتریس دسترسی) فقط تست میدانی — کد frontend ممیزی محتوایی نشده
- سخت‌افزار (دوربین/باریر/چاپگر/POS/UPS): شبیه‌سازی — اتصال واقعی نیازمند تجهیز
