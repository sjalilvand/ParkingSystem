# ساختار منو (الحاقیه §۱) — دو سطح اول

منوی سامانه در دو بخش اصلی سازمان‌دهی شده است. هر بخش شامل «گروه‌ها» است و
هر گروه ممکن است زیرمجموعه داشته باشد. فیلتر مجوز (RBAC) در تمام سطوح اعمال
می‌شود و گروه خالیِ بی‌مجوز نمایش داده نمی‌شود.

برای اپراتور گیت، «پنل گیت» دکمهٔ بزرگ و پین‌شدهٔ بالای منو است (ساده/بزرگ).

## بخش دوم: شبیه‌ساز و آزمون سناریوها (۹ گروه)

همهٔ صفحات این بخش برچسب الزامی «آزمایشی ـ فاقد اعتبار مالی و عملیاتی»
(SimBanner) دارند و روی پایگاه‌دادهٔ جداگانهٔ شبیه‌ساز کار می‌کنند.

| # | گروه | آیتم‌ها | مسیر | مجوز کنترل |
|---|---|---|---|---|
| ۱ | محیط شبیه‌سازی | شبیه‌ساز ترافیک | `/simulator` | simulator.view |
| ۲ | سناریوهای الزامی | کاتالوگ SIM-01..20 | `/sim-scenarios` | simulator.view |
| ۳ | سناریوی آموزشی | گام‌به‌گام ۵ فاز | `/simulator` | simulator.view |
| ۴ | رویداد دستی گیت | ثبت رویداد دستی | `/simulator` | simulator.view |
| ۵ | سناریوساز | دادهٔ آزمایشی و پاکسازی | `/scenario` | settings.view |
| ۶ | آزمایش قوانین | تستر قوانین | `/rule-tester` | rules.view |
| ۷ | آزمایش پلاک‌خوان | پلاک‌خوان OCR | `/plate-ocr` | (باز) |
| ۸ | آزمون مجوز و پلاک | بازبینی پلاک (آزمایشی) | `/plate-review` | gate.view |
| ۹ | راهنمای جداسازی | وضعیت جداسازی محیط | `/sim-scenarios` | simulator.view |

نکتهٔ گروه‌های ۳ و ۴: صفحهٔ «شبیه‌ساز ترافیک» شامل هر دو بخش آموزش گام‌به‌گام
و رویداد دستی است؛ ورودی‌های مستقل منو برای دسترسی سریع نقش‌های آموزشی هستند.
گروه ۹ به کارت «جداسازی محیط» در پایین صفحهٔ سناریوها اشاره دارد (آدرس DB
شبیه‌ساز بدون پسورد نمایش داده می‌شود).

## قواعد رفتار
- سطح اول (بخش‌ها) تاشو است؛ وضعیت پیش‌فرض: عملیاتی باز، شبیه‌ساز بسته.
- گروه تک‌آیتمی با یک کلیک مستقیم به مقصد می‌رود (بدون لایهٔ اضافی).
- آیتم فعال با رنگ اصلی مشخص و بولد می‌شود.
- مجوزها از `/auth/me` خوانده می‌شوند و در سطح API هم enforce می‌شوند
  (فیلتر منو فقط راحتی است، نه سد امنیتی).
