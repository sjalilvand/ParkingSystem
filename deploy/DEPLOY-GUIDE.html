🚀 راهنمای گام‌به‌گام استقرار سامانه پارکینگ روی سرور

معماری نسخه سرور: همه سرویس‌ها داخل Docker اجرا می‌شوند — nginx (وب + پروکسی API/WebSocket) → backend (FastAPI) → postgres / redis / minio. در اولین اجرا، بک‌اند به‌صورت خودکار: ساخت کامل جدول‌ها، کاربر ادمین، نقش ADMIN، دو گیت پیش‌فرض و ۴۶۳ کد پلاک استان/شهرستان را bootstrap می‌کند.

۲نصب Docker (اوبونتو)

sudo apt update && sudo apt install -y ca-certificates curl git
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] \
  https://download.docker.com/linux/ubuntu $(. /etc/os-release && echo $VERSION_CODENAME) stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
sudo usermod -aG docker $USER
# logout/login کنید، بعد تست:
docker run --rm hello-world

🖥 ویندوز سرور: Docker Desktop را نصب کنید (Settings → General → Start when you sign in). بقیه مراحل یکسان است؛ فقط به‌جای bash از PowerShell و به‌جای nano از notepad استفاده کنید.

۳دریافت کد پروژه

روش الف — از گیت‌هاب (پیشنهادی):

git clone https://github.com/sjalilvand/ParkingSystem.git
cd ParkingSystem

روش ب — بدون اینترنت (کپی از سیستم فعلی):

# روی سیستم فعلی (PowerShell):
git archive --format=zip -o C:\Users\%USERNAME%\Desktop\parking-deploy.zip HEAD
# فایل zip را با فلش/شبکه به سرور ببرید و Extract کنید

۴ساخت فایل تنظیمات امن (.env.prod)

cp .env.prod.example .env.prod
nano .env.prod        # در ویندوز: notepad .env.prod

برای تولید مقادیر امن <GENERATE> (۳ بار برای APP_SECRET_KEY و JWT_SECRET_KEY و POSTGRES_PASSWORD و MINIO_SECRET_KEY و GATE_API_KEY):

python3 -c "import secrets; print(secrets.token_urlsafe(48))"
# یا در ویندوز PowerShell:
# [Convert]::ToBase64String((1..48 | %{Get-Random -Maximum 256}))

⚠️ حتماً DEFAULT_ADMIN_PASSWORD را یک رمز قوی بگذارید و جایی امن ذخیره کنید. فایل .env.prod هرگز commit نمی‌شود (در .gitignore هست).

۵اجرای استقرار

docker compose -f docker-compose.prod.yml --env-file .env.prod up -d --build

اولین build چند دقیقه طول می‌کشد. سپس وضعیت و لاگ bootstrap:

docker compose -f docker-compose.prod.yml ps
docker compose -f docker-compose.prod.yml logs -f backend
# منتظر این خط بمانید:  [bootstrap] BOOTSTRAP OK
# خروج: Ctrl+C  (سرویس‌ها در پس‌زمینه ادامه می‌دهند)

✅ تست سلامت: curl http://localhost/health/live ← باید {"status":"ok"} بدهد

۶ورود اولیه و تغییر رمز (الزامی)

  1. مرورگر: http://IP-سرور ← صفحه لاگین
  2. ورود با admin و رمزی که در .env.prod گذاشتید
  3. آیکون 🔒 در نوار بالا ← تغییر رمز عبور ← رمز جدید
  4. بررسی صفحات: داشبورد، مرکز عملیات، پنل گیت

۷فایروال (اوبونتو)

sudo ufw allow 22/tcp
sudo ufw allow 80/tcp
sudo ufw enable
sudo ufw status

⚠️ پورت‌های 5432 (postgres)، 6379 (redis)، 9000/9001 (minio) عمداً به بیرون باز نشده‌اند — فقط داخل شبکه Docker. دسترسی از بیرون فقط از طریق nginx/پورت 80.

۸اتصال ماشین گیت (سیستم فعلی شما) به سرور

فایل gate-agent\.env روی سیستم گیت را ویرایش کنید:

CENTRAL_API_URL=http://IP-سرور/api/v1
GATE_API_KEY=<همان GATE_API_KEY در .env.prod سرور>

و در backend\.env.prod سرور، CORS_ALLOWED_ORIGINS=http://IP-سرور باشد (پیش‌فرض همین است). سپس سرویس‌های گیت را ری‌استارت کنید. دوربین ANPR همچنان به همان سیستم گیت POST می‌زند (پورت 8092 محلی) و پل، رویداد را به سرور می‌فرستد.

اگر فرم گوگل‌شیت هم دارید: در Code.gs مقدار API_BASE را به http://IP-سرور/api/v1 تغییر دهید و Deploy ← New version بزنید.

۹بکاپ‌گیری خودکار از دیتابیس

# بکاپ دستی:
docker compose -f docker-compose.prod.yml exec postgres \
  pg_dump -U parking parking_db > backup_$(date +%F).sql

# بکاپ روزانه ساعت 3 بامداد (cron):
crontab -e
# این خط را اضافه کنید:
0 3 * * * cd /path/to/ParkingSystem && docker compose -f docker-compose.prod.yml exec -T postgres pg_dump -U parking parking_db > ~/backups/parking_$(date +\%F).sql

۱۰به‌روزرسانی نسخه‌های بعدی

git pull
docker compose -f docker-compose.prod.yml --env-file .env.prod up -d --build

داده‌ها در volume ها (pgdata/miniodata) حفظ می‌شوند.

۱۱عیب‌یابی

مشکلدستور بررسی
صفحه باز نمی‌شودdocker compose -f docker-compose.prod.yml ps — همه باید Up باشند
خطای backenddocker compose -f docker-compose.prod.yml logs --tail 50 backend

✅ چک‌لیست نهایی تحویل

  • Docker نصب و hello-world موفق
  • کد روی سرور (clone یا zip)
  • .env.prod با مقادیر امن ساخته شد
  • up -d --build موفق و BOOTSTRAP OK در لاگ backend
  • http://IP-سرور بالا آمد و ورود ادمین موفق
  • رمز ادمین تغییر کرد
  • ufw فعال (فقط 22 و 80)
  • gate-agent به IP سرور متصل شد (مرکز عملیات ← گیت‌ها آنلاین)
  • دوربین ANPR تست شد و رویداد در «تردد» ثبت شد
  • cron بکاپ روزانه تنظیم شد
