🚀 راهنمای کامل استقرار سامانه پارکینگ روی Windows 10

نقشه راه: ویندوز ۱۰ شما با لایه‌ای به‌نام WSL2 یک اوبونتو واقعی داخل خودش اجرا می‌کند؛ Docker Desktop روی همین اوبونتو سوار می‌شود و کل سامانه (nginx + backend + postgres + redis + minio) داخل کانتینرها بالا می‌آید. سپس کل داده‌های سیستم فعلی (دیتابیس + عکس‌ها) با دو اسکریپت آماده منتقل می‌شود.

تفکیک نقش‌ها بعد از استقرار:
🖥 سرور (ویندوز ۱۰ جدید): برنامه + دیتابیس — مرورگرها به آن وصل می‌شوند (پورت 80)
🚧 سیستم فعلی (گیت): فقط gate-agent + پل دوربین ANPR — به سرور وصل می‌شود

۰آماده‌سازی ویندوز تازه‌نصب

  1. Windows Update را تا آخر اجرا کنید و ری‌استارت کنید (Settings → Windows Update).
  2. نسخه ویندوز: Win+R ← winver ← باید نسخه 2004 به بالا (ساخت 19041+) باشد. (Windows 10 Home هم کافی است.)
  3. مجازی‌سازی CPU: Task Manager ← تب Performance ← CPU ← باید Virtualization: Enabled باشد. اگر Disabled است، در BIOS مادربرد گزینه Intel VT-x / AMD-V (SVM) را Enable کنید.
  4. IP ثابت (مهم!): Settings ← Network & internet ← Ethernet ← IP assignment ← Edit ← Manual ← IPv4 ON:
    فیلدمثال (طبق شبکه خودتان تنظیم کنید)
    IP address192.168.1.50
    Subnet mask255.255.255.0
    Gateway192.168.1.1
    DNS192.168.1.1 یا 8.8.8.8
  5. هرگز خاموش/خواب نشود: Settings ← System ← Power ← Screen and sleep ← هر دو گزینه Never.
  6. این IP را جایی یادداشت کنید — از این‌جا به بعد «IP-سرور» همان است.

۱نصب WSL2 + اوبونتو داخل ویندوز

WSL2 یعنی «Windows Subsystem for Linux نسخه ۲» — یک اوبونتو واقعی داخل ویندوز، بدون ماشین‌مجازی سنگین و بدون Dual-Boot.

  1. PowerShell را Run as Administrator باز کنید و بزنید: 
    wsl --install
    این دستور WSL2 + یک اوبونتو پیش‌فرض نصب می‌کند. (اگر خطای منابع داد: wsl --install -d Ubuntu-22.04)
  2. ری‌استارت کنید.
  3. پنجره اوبونتو خودش باز می‌شود و می‌پرسد UNIX username / password — هر نامی بگذارید (مثلا parking) و رمزش را بگذارید. این رمز فقط مال محیط اوبونتو است و با ویندوز کاری ندارد.
  4. تست نسخه: 
    wsl -l -v
    باید Ubuntu ... VERSION 2 ببینید.

🔗 رابطه ویندوز و اوبونتو (خیلی مهم)

موضوعتوضیح
فایل‌های ویندوز از اوبونتودرایو D شما در اوبونتو روی مسیر /mnt/d است — مثلا ls /mnt/d/Projects
فایل‌های اوبونتو از ویندوزدر File Explorer آدرس \\wsl$\Ubuntu را باز کنید
شبکه (localhost)دوطرفه مشترک است — پورتی که اوبونتو/داکر باز کند از ویندوز با همان localhost در دسترس است (و برعکس)
ترمینالمی‌توانید همه کارها را با همان PowerShell انجام دهید؛ داکر که نصب شود از PowerShell هم کنترل می‌شود. ترمینال اوبونتو اختیاری است.
💡 نقش اوبونتو این‌جا فقط «موتور» Docker است. شما لازم نیست دستور لینوکسی بزنید — همه‌چیز از PowerShell انجام می‌شود.

۲نصب Docker Desktop

  1. از https://www.docker.com/products/docker-desktop/ فایل Docker Desktop Installer.exe را دانلود و نصب کنید (در صفحۀ نصب گزینه Use WSL 2 instead of Hyper-V تیک‌خورده بماند).
  2. Docker Desktop را اجرا کنید ← قرارداد را Accept کنید (لاگین گوگل/اکانت لازم نیست، Skip کنید).
  3. Settings (چرخ‌دنده) ← General ← تیک Start Docker Desktop when you sign in ← Apply.
  4. Settings ← Resources ← WSL Integration ← گزینه Ubuntu را روشن کنید ← Apply & Restart.
  5. تست — در PowerShell (عادی): 
    docker run --rm hello-world
    باید پیام Hello from Docker! را ببینید.
اگر خطای «WSL 2 installation is incomplete» دیدید: PowerShell ادمین ← wsl --update ← ری‌استارت.

۳انتقال کد پروژه به سرور

روش الف — اینترنت دارد:

cd D:\
git clone https://github.com/sjalilvand/ParkingSystem.git
cd ParkingSystem

روش ب — بدون اینترنت (از سیستم فعلی):

# روی سیستم فعلی (PowerShell):
cd D:\Projects\ParkingSystem
git archive --format=zip -o $env:USERPROFILE\Desktop\parking-deploy.zip HEAD
# فایل zip را به سرور ببرید، در D:\ParkingSystem باز کنید (Extract)

برای سرعت (غیرفعال‌کردن اسکن Defender روی پروژه) — PowerShell ادمین:

Add-MpPreference -ExclusionPath "D:\ParkingSystem"

۴ساخت فایل تنظیمات امن (.env.prod)

cd D:\ParkingSystem
copy .env.prod.example .env.prod
notepad .env.prod

برای هر ۵ مقدار <GENERATE> یک رمز یکتا بسازید — در PowerShell هر بار:

-join ((48..57)+(65..90)+(97..122) | Get-Random -Count 40 | % {[char]$_})
کلیدتوضیح
APP_SECRET_KEY / JWT_SECRET_KEYهر کدام یک رشته تصادفی ۴۰ کاراکتری
POSTGRES_PASSWORDرمز دیتابیس
MINIO_SECRET_KEYرمز فایل‌سرور
GATE_API_KEYکلید اتصال سیستم گیت — این را یادداشت کنید (برای گام ۹ لازم است)
DEFAULT_ADMIN_PASSWORDرمز ورود اولیه ادمین — قوی و یادداشت‌شده
CORS_ALLOWED_ORIGINShttp://IP-سرور (مثلا http://192.168.1.50)

⚠️ فایل .env.prod را از دست ندهید — نسخه پشتیبان امن از آن نگه دارید (هرگز در گیت/ایمیل نیست).

۵انتقال داده‌ها از سیستم فعلی (دیتابیس + عکس‌ها)

۵-۱) روی سیستم فعلی (گیت):

cd D:\Projects\ParkingSystem
powershell -File deploy\export-data.ps1

خروجی: parking-migration-…zip روی دسکتاپ شامل parking_backup.sql + پوشه minio (عکس ساکنین).

۵-۲) انتقال به سرور:

zip را کپی کنید (اشتراک شبکه: راست‌کلیک ← Give access to، یا فلش) و در سرور Extract کنید — مثلا C:\parking-migration.

۵-۳) روی سرور — فقط دیتابیس را بالا بیاورید:

cd D:\ParkingSystem
docker compose -f docker-compose.prod.yml --env-file .env.prod up -d postgres

۵-۴) Import:

powershell -File deploy\import-data.ps1 -BackupDir "C:\parking-migration"

✅ باید ببینید: «vehicles rows restored: N» و «MinIO restore OK»

ترتیب حیاتی است: Import قبل از بالا آوردن کل استک انجام شود (چون bootstrap فقط روی دیتابیس خالی می‌سازد؛ دیتابیسِ restore‌شده را دست نمی‌زند).

۶اجرای کامل سامانه

docker compose -f docker-compose.prod.yml --env-file .env.prod up -d --build

اولین build چند دقیقه طول می‌کشد (دانلود base image ها). سپس:

docker compose -f docker-compose.prod.yml ps
docker compose -f docker-compose.prod.yml logs --tail 30 backend

✅ همه ۵ سرویس باید Up باشند و در لاگ backend خط [bootstrap] BOOTSTRAP OK دیده شود (چون دیتابیس restore شده، فقط چک می‌کند و رد می‌شود).

تست سلامت: curl http://localhost/health/live ← {"status":"ok"}

۷ورود اولیه و تغییر رمز (الزامی)

  1. از هر کامپیوتری در شبکه: مرورگر ← http://IP-سرور
  2. ورود: admin / رمزی که در .env.prod گذاشتید (اگر دیتابیس از سیستم قبلی آمده، رمز قبلی Admin@1234 است!)
  3. فوراً آیکون 🔒 نوار بالا ← تغییر رمز عبور.
  4. بازدید صفحات: داشبورد، خودروها (دیتای قبلی هست؟)، مرکز عملیات.

بازیابی رمز در صورت فراموشی (PowerShell در پوشه پروژه سرور):

docker compose -f docker-compose.prod.yml exec backend python -m scripts.reset_admin --password "NewStrong@123"

۸فایروال ویندوز سرور

netsh advfirewall firewall add rule name="ParkingHTTP" dir=in action=allow protocol=tcp localport=80
netsh advfirewall firewall add rule name="RDP" dir=in action=allow protocol=tcp localport=3389

بررسی اشغال پورت ۸۰ (IIS گاهی اشغال می‌کند):

netstat -ano | findstr ":80 "
# اگر PID متعلق به سرویس "World Wide Web Publishing" بود:
net stop W3SVC
sc config W3SVC start= disabled

postgres/redis/minio عمداً به بیرون باز نیستند — فقط از داخل شبکه Docker. دسترسی بیرونی فقط nginx (پورت 80).

۹اتصال سیستم گیت و فرم گوگل به سرور

  1. روی سیستم گیت (سیستم فعلی): فایل D:\Projects\ParkingSystem\gate-agent\.env را ویرایش کنید: 
    CENTRAL_API_URL=http://IP-سرور/api/v1
GATE_API_KEY=مقدار-همان-GATE_API_KEY-در-env.prod-سرور
  2. غیرفعال کردن سرویس‌های «سرور قبلی» روی سیستم گیت (تا دوتا سرور موازی نشویم): 
    Unregister-ScheduledTask -TaskName "ParkingSystem-Watchdog" -Confirm:$false
Unregister-ScheduledTask -TaskName "ParkingSystem-AutoStart" -Confirm:$false
    (فقط gate-agent و ANPR bridge این‌جا می‌مانند.)
  3. ری‌استارت agent و ANPR روی سیستم گیت ← در سرور: مرکز عملیات ← «گیت ورودی: آنلاین» ✓
  4. دوربین ANPR نیازی به تغییر ندارد (به همان سیستم گیت POST می‌زند، پل به سرور می‌فرستد).
  5. فرم گوگل‌شیت (اگر دارید): در Code.gs مقدار API_BASE ← http://IP-سرور/api/v1 و Deploy ← New version.

۱۰خودراه‌اندازی بعد از ری‌استارت سرور

سه لایه خودکار دارید: ۱) Docker Desktop با Start when sign in بالا می‌آید ۲) کانتینرها با restart: unless-stopped خودشان برمی‌گردند ۳) داده‌ها در volume دائمی‌اند.

تست: سرور را یک‌بار Restart کنید ← بعد از لاگین و ۲-۳ دقیقه ← http://localhost باید بالا باشد.

اگر سرور رمز ویندوز دارد و بعد از برق‌قطعی کسی لاگین نمی‌کند، داکر بالا نمی‌آید. راه‌حل اختیاری: Win+R ← netplwiz ← تیک «Users must enter…» را بردارید (ریسک امنیتیphysical — با فایروال و محل بسته جبران کنید).

۱۱بکاپ روزانه (Task Scheduler)

فایل D:\ParkingSystem\deploy\daily-backup.ps1 بسازید:

$d = "D:\backups"; New-Item -ItemType Directory -Force $d | Out-Null
 $cid = docker compose -f D:\ParkingSystem\docker-compose.prod.yml ps -q postgres
docker exec $cid pg_dump -U parking parking_db -f /tmp/b.sql
docker cp "${cid}:/tmp/b.sql" "$d\parking_$(Get-Date -Format yyyyMMdd).sql"
Get-ChildItem $d -Filter parking_*.sql | Sort-Object LastWriteTime -Desc | Select-Object -Skip 14 | Remove-Item -Force

Task Scheduler ← Create Basic Task ← نام: ParkingBackup ← Daily 03:00 ← Start a program ← powershell.exe ← Arguments: -File D:\ParkingSystem\deploy\daily-backup.ps1

۱۲به‌روزرسانی نسخه‌های بعدی

cd D:\ParkingSystem
git pull
docker compose -f docker-compose.prod.yml --env-file .env.prod up -d --build

داده‌ها حفظ می‌شوند (volume ها). .env.prod را دست نزنید.
